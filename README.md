# איך להעלות ולהתקין את האפליקציה - מהטלפון בלבד

האפליקציה עצמה (השלד) צריכה "כתובת אינטרנט" אמיתית כדי שההתראות יעבדו. זה **חד פעמי** - אחרי זה הכל רץ מקומית בטלפון.

## שלב 1: יצירת חשבון GitHub (אם אין לך)
1. פתח דפדפן בטלפון (כרום מומלץ) ובגלוש ל-github.com
2. הירשם (Sign up) עם מייל - חינמי לגמרי.

## שלב 2: יצירת "מאגר" (Repository) חדש
1. אחרי ההתחברות, לחץ על "+" למעלה → **New repository**
2. שם למאגר: `projects-app` (או כל שם באנגלית, בלי רווחים)
3. סמן **Public**
4. סמן **Add a README file**
5. לחץ **Create repository**

## שלב 3: העלאת הקבצים
1. בתוך המאגר, לחץ **Add file → Upload files**
2. בחר מהטלפון את **כל 5 הקבצים ביחד** (אפשר לסמן כמה קבצים בו-זמנית בבורר הקבצים):
   - `index.html`
   - `manifest.json`
   - `sw.js`
   - `icon-192.png`
   - `icon-512.png`
3. לחץ **Commit changes**

כל הקבצים נמצאים באותה רמה (בלי תיקיות משנה), כך שאין צורך לשחק עם שמות נתיבים - פשוט מעלים את כולם יחד באותה פעולה.

## שלב 4: הפעלת GitHub Pages
1. בתוך המאגר, לחץ **Settings** (בתפריט העליון)
2. בתפריט הצד, לחץ **Pages**
3. תחת "Branch", בחר **main** ותיקייה **/(root)**, ואז **Save**
4. חכה דקה-שתיים, רענן את העמוד - תופיע כתובת בסגנון:
   `https://<שם-המשתמש-שלך>.github.io/projects-app/`

## שלב 5: התקנה בטלפון
1. פתח את הכתובת הזו בדפדפן באנדרואיד (כרום, אדג', בריב, סמסונג אינטרנט או פיירפוקס - כולם נתמכים)
2. יופיע פס/תפריט "הוסף למסך הבית" (Add to Home screen / Install app) - לחץ עליו
3. האפליקציה תופיע כאייקון במסך הבית, נפתחת כמו אפליקציה רגילה

## שלב 6: הפעלת התראות
1. פתח את האפליקציה → עבור ללשונית "הגדרות וגיבוי"
2. לחץ "בקש הרשאת התראות" ואשר בחלון שנפתח

## חשוב לדעת
- **כל המידע** (פרויקטים, משימות, אנשי קשר) נשמר **רק בטלפון שלך**, בזיכרון הדפדפן המקומי. שום דבר לא נשלח לשום שרת.
- מומלץ לבצע גיבוי מדי פעם דרך "הגדרות וגיבוי → ייצוא גיבוי" ולשמור את הקובץ (למשל בגוגל דרייב) - כדי שלא לאבד מידע אם מוחקים את נתוני הדפדפן.
- התראות עובדות היטב כשהאפליקציה פתוחה/ברקע. אם האפליקציה/הדפדפן סגורים לגמרי לאורך זמן רב, ייתכן שהתראה תוחמץ - זו מגבלת אנדרואיד ולא ניתן לעקוף אותה בלי שרת Push אמיתי.
- אם בעתיד תרצה לעדכן את קובץ `index.html` או `sw.js` (שדרוגים), פשוט תעלה גרסה חדשה דרך GitHub באותו תהליך של שלב 3 - זה לא ימחק את הנתונים השמורים בטלפון.

## עדכון: פיצ'רים חדשים בגרסה הזו
- **מצב יום/לילה**: בלשונית "הגדרות" - ברירת מחדל אוטומטי לפי המכשיר, אפשר לעקוף ידנית.
- **תזכורות ללא הגבלה**: בכל משימה/תת-משימה אפשר להוסיף כמה תזכורות נפרדות שתרצה, בנוסף לתאריך היעד.
- **לקוחות/חברות היררכיים**: לשונית "אנשי קשר" → "לקוחות/חברות". לכל לקוח/חברה אפשר להגדיר "שייך ל..." (למשל בילינסון שייך לכללית).
- **מסך משימות באיחור**: לחיצה על הבאנר האדום, או פופאפ שקופץ אוטומטית בכל פתיחת האפליקציה אם יש איחורים.
- **לחיצה על התראה** מעבירה ישירות למשימה/תת-משימה/תת-תת-משימה הרלוונטית.
- **ייבוא/ייצוא CSV** ללקוחות/חברות ולאנשי קשר, מתוך לשונית "אנשי קשר".

### פורמט קובץ CSV לייבוא לקוחות/חברות
כותרות עמודות (שורה ראשונה בקובץ, באנגלית): `name, parent, phone, address, website, notes`
- `name` - שם הלקוח/חברה (חובה)
- `parent` - שם החברה-האם, אם יש (למשל: אם השורה היא "בילינסון", אפשר לשים "כללית" בעמודת parent) - אופציונלי
- שאר העמודות אופציונליות

### פורמט קובץ CSV לייבוא אנשי קשר
כותרות עמודות: `name, role, company, phone, email, notes`
- `name` - שם איש הקשר (חובה)
- `company` - שם הלקוח/חברה אליו הוא שייך (אם הלקוח לא קיים במערכת, הוא ייווצר אוטומטית) - אופציונלי
- שאר העמודות אופציונליות

## עדכון נוסף
- **תזכורות נוספות חוזרות**: כל תזכורת נוספת אפשר להגדיר כחוזרת, ולבחור אופן חזרה: יומי/שבועי/חודשי/ימי עבודה/סוף שבוע/ימים ספציפיים.
- **הגדרות שבוע עבודה**: בלשונית "הגדרות" - בחירת יום ראשון בשבוע, וסימון אילו ימים הם "ימי עבודה" (משפיע על אפשרויות התזכורת).
- **כיווץ/הרחבת תתי-משימות**: חץ קטן ליד כל פריט עם תתי-משימות, בנוסף לכפתורי "הרחב הכל"/"כווץ הכל" ואפשרות לקבוע ברירת מחדל בהגדרות.
- **לחיצה על איש קשר** (בכל מקום באפליקציה) פותחת חלונית עם כפתורי חיוג, שליחת אימייל וניווט (Google Maps / Waze) לכתובת שלו.
- **הוספה ליומן Google**: כפתור בכל משימה (רק אם יש תאריך יעד), וגם תיבת סימון במסך העריכה שפותחת את ההוספה אוטומטית בעת השמירה. אפשר להגדיר בהגדרות מזהה יומן ספציפי (Calendar ID) כדי שהאירוע ייפתח מוכן על היומן הנכון.

## עדכון גדול נוסף
- **דשבורד חדש** (לשונית נפרדת): כרטיסי סיכום, 8 המשימות הדחופות ביותר, 7 הימים הקרובים לפי יום, התקדמות לפי פרויקט, פילוח פרויקטים לפי סטטוס, לקוחות/חברות עם הכי הרבה משימות פתוחות.
- **חיפוש** בראש מסך הפרויקטים - מחפש בשם/הערות הפרויקט, ובכל המשימות/תתי-משימות/תתי-תת-משימות (כותרת, תיאור, אנשי קשר, חברות וחברות-אם) בכל עומק.
- **מיון וסינון**: משימות שהושלמו יורדות אוטומטית לתחתית הרשימה בכל רמה, ואפשר לסמן "הסתר הושלמו" בכל פרויקט.
- **"הושלם באפקט"**: כשמסמנים פריט כהושלם, תתי-הפריטים שלו לא מקבלים סימון חזותי (בלי קו חוצה), אבל הם לא נספרים יותר בבאנר/במסך איחורים, והתזכורות שלהם מושהות (לא נמחקות - חוזרות לפעול אם מבטלים את הסימון "הושלם").
- **איש קשר ראשי** - ניתן לבחור בפרויקט, במשימה, בתת-משימה ובתת-תת-משימה (מתוך אנשי הקשר המשויכים). הכתובת שלו משמשת כמיקום באירוע ביומן; אם לפריט אין איש קשר ראשי משלו, המערכת עולה בהיררכיה (תת-תת-משימה ← תת-משימה ← משימה ← פרויקט) עד שהיא מוצאת אחד.
- **שדה "מנהל/ת"** באיש קשר - קישור לאיש קשר אחר מהרשימה כמנהל שלו.
- **שיפורי יומן Google**: כותרת האירוע = "שם פרויקט - שם משימה", בהערות מופיעים שמות וטלפונים של אנשי הקשר המשויכים + קישור חזרה למשימה באפליקציה (דורש מילוי "כתובת האתר שלי" בהגדרות).
- **קישורים מהירים לאפליקציות מותקנות**: בהגדרות, מוסיפים שם + כתובת https רגילה של השירות (למשל https://wa.me/, https://waze.com/) - באנדרואיד זה יפתח את האפליקציה המותקנת ישירות בזכות מנגנון App Links, לא רק את האתר. הכפתורים מופיעים בראש מסך הפרויקטים והדשבורד.
- **עיצוב מחודש** בהשראת Material Design 3 - פינות מעוגלות יותר, צבעים טונליים, צלליות עדינות, תגיות סטטוס ברורות יותר.
- הוחלט לוותר על נעילת סיסמה יומית.

## עדכון: לוגו לקוחות
- **לוגו אוטומטי לכל לקוח/חברה** - נמשך מהאינטרנט לפי שדה "אתר אינטרנט" שממלאים בכרטיס החברה, דרך שירות ה-Favicon החינמי של Google (בלי הרשמה). אם אין שדה אתר, לא יוצג לוגו (רק אייקון 🏢).
- **בחירת לקוח/חברה הפכה לחובה** ביצירת פרויקט חדש (שדה נפרד מ"אנשי קשר").
- הלוגו מוצג בכל מקום שהחברה מופיעה: רשימת פרויקטים, כותרת פרויקט, רשימת לקוחות/חברות, כרטיסי אנשי קשר, ודשבורד.
- מיקום אירוע ביומן: אם לא נמצא איש קשר ראשי עם כתובת, המערכת תיפול כעת גם לכתובת הלקוח/חברה של הפרויקט עצמו.

## תיקון: קישורים מהירים ולוגו
- **קישורים מהירים תוקנו**: עכשיו זה פותח אפליקציה מותקנת ישירות לפי "שם חבילה" (Package name) - עובד גם לאפליקציות בלי אתר בכלל. הוראות למציאת שם החבילה נמצאות בהגדרות עצמן.
- **לוגו לא מופיע?** ודא שמילאת את השדה "אתר אינטרנט" בכרטיס העריכה של כל לקוח/חברה (לשונית אנשי קשר ← לקוחות/חברות ← לחיצה על עיפרון העריכה). בלי שדה אתר, אין דרך למשוך לוגו - זה לא באג, זה חסר מידע.

## עדכון: מספר גרסה + תיקון קישורים מהירים
- **מספר גרסה** מוצג עכשיו ליד הכותרת הראשית (טקסט קטן) וגם בכרטיס "אודות" חדש בהגדרות. אם אחרי עדכון קבצים המספר לא השתנה - זה סימן שהדפדפן מציג גרסה שמורה במטמון, לא שההעלאה נכשלה (ראה טיפ ניקוי מטמון למעלה).
- **תיקון קישורים מהירים**: תוקן תחביר ה-intent (חסרו `//` ונקודה-פסיק בסוף) שגרם להפניה שגויה ל-Play Store.

## עדכון: מצב פוקוס, הגדרות מתקפלות, אנימציות
- **מסך הגדרות** מחולק ל-4 כותרות נפתחות (אקורדיון): כללי, יומן ואפליקציות, התראות, גיבוי ומידע - הכל סגור כברירת מחדל, רק אחת פתוחה בו-זמנית.
- **מצב פוקוס**: לחיצה על כותרת משימה/תת-משימה פותחת חלונית עם כל הפרטים, כולל רשימת תת-פריטים שאפשר ללחוץ עליהם למעבר לפוקוס שלהם, וכפתורי עריכה/סימון השלמה/הוספת תת-פריט/יומן/מחיקה.
- **סימון השלמה** עבר לכפתור ייעודי (✅/↩️) ליד העריכה/מחיקה בשורת המשימה - לחיצה על הכותרת עצמה כבר לא מסמנת השלמה, אלא פותחת את מצב הפוקוס.
- **אנימציות מהירות** (כ-140-160ms): פתיחה/סגירה של חלוניות, מעבר בין לשוניות, וכיווץ/הרחבת תתי-משימות.
- **קישורים מהירים** - הוסרה אופציית האייקון (מוצג רק שם האפליקציה), ונוספה אפשרות לערוך קישור קיים (לא רק להוסיף/למחוק).
- **מספר גרסה** מתאחד עם שם קובץ ה-ZIP (זהה בדיוק), בפורמט תאריך_שעה בשעון ישראל, מוצג רק בכרטיס "אודות" תחת "גיבוי ומידע".

## עדכון גדול: ניווט מחדש + תיקון סופי לאפליקציות
- **תיקון אמיתי לקישורי אפליקציות**: הכפתורים עכשיו הם קישורי `<a>` אמיתיים (לא JavaScript) - זו כנראה הסיבה שזה נכשל גם בכרום. נגישים דרך הכפתור הצף החדש (📱, פינה ימנית תחתונה).
- **פאנל ניווט צד** בסגנון Edge Panel של סמסונג: פס דק לאורך כל הדופן הימנית - לחיצה או גרירה פותחת תפריט עם דשבורד/פרויקטים/אנשי קשר/הגדרות.
- **הכותרות העליונות (הלשוניות) הוסרו** - הניווט עבר לגמרי לפאנל הצד.
- **דשבורד הוא מסך הבית** כברירת מחדל, עם כפתור "מעבר לפרויקטים" בולט בראש המסך.
- **"הכי דחופות"** משתמש כעת בחלון של 3 ימים (במקום 7).
- **"7 הימים הקרובים"** מציג רק ימים שבהם יש בפועל משימות.
- **כפתור "השלמת פרויקט"** (✅) בעמוד הפרויקט - מעביר לסטטוס "נסגר בהצלחה" בלבד, לא נוגע במשימות.

### הקמת Client ID של Google (חד פעמי, מהטלפון)
1. היכנס ל-console.cloud.google.com עם חשבון Google שלך, ובחר **פרויקט חדש** (New project), למשל `PT-backup`.
2. תפריט ← **APIs & Services** ← **Library** ← חפש **Google Drive API** ← **Enable**.
3. **OAuth consent screen** (או Google Auth Platform): סוג **External**, שם אפליקציה (כל שם), המייל שלך. במצב **Testing** הוסף את המייל שלך תחת **Test users**.
4. **Credentials** ← **Create credentials** ← **OAuth client ID** ← סוג **Web application**.
5. תחת **Authorized JavaScript origins** הוסף את כתובת האתר שלך בלבד, בלי נתיב: `https://<שם-המשתמש>.github.io`
6. **Create**, והעתק את ה-Client ID (נגמר ב-`.apps.googleusercontent.com`).
7. באפליקציה: הגדרות וגיבוי ← שדה Client ID ← הדבק ← **התחבר** ואשר.
- ההעלאה מתבצעת כשהאפליקציה פתוחה. אין refresh token, ולפעמים Google תבקש אישור מחדש.
- האפליקציה רואה רק קבצים שהיא עצמה יצרה (הרשאת `drive.file`).
